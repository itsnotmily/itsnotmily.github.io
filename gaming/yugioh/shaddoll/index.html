Shaddoll Deck 🧵

  • Main gameplan: Use Lev Shaddoll Fusion to load the GY and establish multiple Shaddoll Fusion monsters.
  • Strengths: Strong GY setup, Fusion recursion, flexible disruption, and powerful Shaddoll boss monsters.
  • Weaknesses: Relies on key GY effects and Fusion plays, making it vulnerable to targeted disruption.
  • Playstyle: Establish Winda as soon as possible while setting up Schism and additional Fusion options for disruption.
  • Below are several dropdowns: the first provides the decklist, and the others showcase different combo paths.
Nightmare Apprentice + 1
🔽

  • Nightmare Apprentice (Activate): Discard 1. Special Summon itself.
  • Nightmare Apprentice (Activate): Add Mirror Swordknight.
  • Normal Summon: Mirror Swordknight.
  • Mirror Swordknight (Activate): Tribute itself. Special Summon Big-Winged Berfomet.
  • Big-Winged Berfomet (Activate): Add Gazelle and Chimera Fusion.
  • Chimera Fusion (Activate): Chimera tKoPB - [ Gazelle + Mirror Swordknight].
  • Chimera tKoPB (1): Gazelle (2): Big-Winged Berfomet (3): Special Summon Mirror Swordknight. Add Coatl.
  • GY: Chimera Fusion > Hand. Set it.
